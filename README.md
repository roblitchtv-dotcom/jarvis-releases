# Jarvis Assistant — versions

Ce dépôt ne contient que les versions publiées de Jarvis Assistant (pas de code) :

- **Installer** : téléchargez `JarvisSetup-<version>.exe` dans la [dernière version](https://github.com/roblitchtv-dotcom/jarvis-releases/releases/latest) et ouvrez-le. Installation pour votre compte, sans droits administrateur.
- **Android** : `jarvis-<version>-android-arm64.apk` dans la même version.
- **Mises à jour** : la release `updates` porte les manifestes `stable.json` et `beta.json` que lisent les Jarvis installés. Chaque paquet est signé (minisign) et vérifié avant toute installation ; une mise à jour n'est installée qu'avec l'accord de l'utilisateur.
